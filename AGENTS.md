# Manutenção deste repositório

Este repositório contém skills e referências. Pedidos de alteração dessas configurações não autorizam criar ou alterar questões, controles e simulados.

Preservar o caráter multibanca: regras gerais nas skills; padrões documentados no repertório por exame/edição; decisões de lote no contrato do lote. Não substituir dados observados por inferências sem identificação.

Papéis de execução: skills/questoes-espelho/references/papeis-de-agentes.md. Revisão visual: skills/questoes-espelho/references/revisao-visual.md. Manutenção do repertório: skills/analisar-provas/references/manutencao.md.

Ao editar, conferir links relativos, JSONs, sintaxe dos scripts e exemplos afetados. Não afirmar revisão pedagógica a partir de validação estrutural. Preservar a licença do humanizer. Não adicionar dados de autenticação nem redistribuir dependências externas por conveniência.
